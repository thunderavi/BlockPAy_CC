# BlockPay Mobile

Expo SDK 57 React Native frontend for the existing BlockPay Express API.

## Temporary UI demo mode

Demo mode is optional and disabled by default so normal development always uses the real Express API and MongoDB data.

- Sender account: `demo@blockpay.app` / `demo123`
- Receiver account: `riya@blockpay.app` / `riya123`
- Payment PIN for both accounts: `1234`

Send money to username `riya`, log out, and sign into the receiver account to see the updated balance, incoming transaction, and payment notification.
- Payment PIN: `1234`

The login form is prefilled. Registration also works locally with any valid-looking values. To reconnect the real Express API, set `EXPO_PUBLIC_DEMO_MODE=false` in `.env` and configure `EXPO_PUBLIC_API_URL`.

## Start

```powershell
npm install
Copy-Item .env.example .env
npx expo start
```

The default `.env.example` uses `http://10.0.2.2:5000/api`, which is the Android Studio emulator alias for the host computer.

## Physical Android device

1. Connect the phone and computer to the same Wi-Fi network.
2. Find the computer's IPv4 address with `ipconfig`.
3. Set `EXPO_PUBLIC_API_URL=http://YOUR_COMPUTER_IP:5000/api` in `.env`.
4. Allow Node.js through Windows Firewall for private networks.
5. Run the backend with `npm run server` from the repository root or `npm run dev` inside `backend/server/`.
6. Run `npm run mobile` from the repository root, or `npx expo start` inside `frontend/mobile/`, and scan the Expo Go QR code.

## Android emulator

Start an Android Studio emulator, keep the default API URL, then run:

```powershell
npx expo start --android
```

## iOS

The iOS simulator requires macOS. Set `EXPO_PUBLIC_API_URL=http://localhost:5000/api`, run `npx expo start --ios`, and ensure the backend is running. A physical iPhone can use Expo Go with the same LAN-IP approach as Android.

## Architecture

The mobile application talks only to the Express REST API. It does not contain MongoDB credentials, JWT secrets, blockchain private keys or RPC secrets. JWTs are stored with Expo SecureStore. QR scanning uses Expo Camera and preserves the existing `BLOCKPAY_QR` JSON format. Blockchain receipts remain generated by the backend; the app reports them as not anchored until the backend exposes genuine anchoring metadata.
